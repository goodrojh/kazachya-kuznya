# Казачья Кузня — лендинг

Одностраничный продающий сайт для производителя шашек, сабель, палашей, шпаг,
кинжалов и ножей «Казачья Кузня».

Контент (тексты, цены, артикулы, FAQ, реквизиты, отзывы) взят с действующего
сайта **kazachya-kuznya.ru** и с профиля компании на Авито.

## Стек

- React 19 + TypeScript
- Vite
- Tailwind CSS 3 (без внешних UI- и icon-библиотек)

## Структура

```
site/
  src/App.tsx             — вся разметка, хуки и компоненты
  src/data.ts             — контент: каталог, товары, отзывы, FAQ, контакты
  src/product-details.ts  — описания и характеристики карточек (генерируется)
  src/legal.ts            — политика конфиденциальности и оферта (генерируется)
  src/index.css           — базовые стили и утилиты
  public/img/             — изображения в WebP
  scripts/                — загрузка и оптимизация исходных данных
```

## Разделы страницы

1. **Прелоадер** — счётчик 0→100 с полосой прогресса.
2. **Первый экран** — три факта-полосы и главная карточка. Все четыре карточки
   показывают разные «окна» одного фонового снимка цеха (техника masked cards).
3. **Каталог** — 8 категорий с количеством позиций.
4. **Изделия** — 24 товара с фильтром по категориям, ценами, скидками и
   артикулами. На карточке — кнопка «В корзину» и быстрый вопрос в WhatsApp;
   клик по фото или названию открывает подробную карточку.
5. **Производство** — конструктивные особенности, ГОСТ Р 51215-98, 5 преимуществ.
6. **Видеообзор** — ролик с канала компании о шашке генерала Бакланова и
   карточка этого же изделия с кнопкой «В корзину».
7. **Отзывы** — 9 реальных отзывов покупателей.
8. **Доставка и вопросы** — аккордеон из 8 вопросов, службы доставки, сроки.
9. **Контакты** — телефон, почта, мессенджеры и форма заявки (уходит в WhatsApp).
10. **Подвал** — реквизиты ИП, иконки соцсетей и юридическая оговорка.

Сквозные элементы: **корзина** (кнопка со счётчиком в шапке и в мобильной
панели) и **иконки соцсетей** — WhatsApp, Telegram, ВКонтакте, YouTube, Авито.

## Карточка товара

Открывается модальным окном по клику на фото или название изделия.

- Галерея из трёх кадров с переключением по миниатюрам.
- Цена, старая цена, размер выгоды, «В корзину» и вопрос в WhatsApp.
- Таблица характеристик: марка стали, длины клинка и рукояти, толщина,
  твёрдость по HRC, вес — всё с карточек текущего сайта.
- Подробное описание и постоянная плашка о сертификате.
- Адрес вида `#product=KSKR0162` открывает карточку напрямую — ссылку можно
  скинуть покупателю. Кнопка «Назад» в браузере закрывает окно.

Описания, характеристики и дополнительные кадры собираются скриптом
`scripts/gen-details.mjs` из выгрузки WooCommerce (`prods.json`, получается
запросом к `/wp-json/wc/store/v1/products` действующего сайта) в файл
`src/product-details.ts`.

## Юридические документы

Политика конфиденциальности и договор оферты открываются модальным окном из
подвала, а также по ссылкам в форме заявки и при оформлении заказа. Тексты
взяты со страниц действующего сайта и собираются в `src/legal.ts` скриптом
`scripts/gen-legal.mjs` — разбор сохраняет нумерацию разделов, определения
терминов и реквизиты продавца.

## Корзина

- Состав хранится в `localStorage` (`kk-cart-v1`) и переживает перезагрузку.
- Выдвижная панель: список позиций с фото, артикулом и ценой за штуку,
  изменение количества, удаление, «Очистить корзину».
- Итоги: количество товаров, выгода относительно базовых цен, сумма заказа.
- Оформление в один шаг: имя, телефон, город, служба доставки и комментарий.
  Заказ уходит в WhatsApp готовым списком — бэкенд не нужен.
- Пустое состояние повторяет формулировки текущего сайта: «Ваша корзина пуста»,
  «Продолжить покупки».

## Разработка

```bash
cd site
npm install
npm run dev
```

## Сборка

```bash
cd site
npm run build
```

Продакшн-сборка публикуется на GitHub Pages через
`.github/workflows/deploy.yml` при пуше в `main`. Базовый путь задаётся
переменной `BASE_PATH`.

## Видео

Ролик подключён «фасадом»: до клика на странице лежит локальное превью в WebP,
и только по нажатию подставляется `<iframe>` с `youtube-nocookie.com`. Так
скрипты YouTube не грузятся при открытии сайта и не ставят куки заранее.

Идентификатор ролика и артикул связанного изделия заданы константами
`VIDEO_ID` и `VIDEO_SKU` в `App.tsx`. При замене ролика нужно также обновить
превью: положить новый кадр в `site/raw` и прописать его в `scripts/optimize.mjs`.

## Обновление изображений

```bash
cd site
node scripts/fetch-src.mjs   # скачивает исходники в site/raw
node scripts/optimize.mjs    # конвертирует в WebP в public/img
```

## Обновление контента с текущего сайта

```bash
cd site
curl -s "https://kazachya-kuznya.ru/wp-json/wc/store/v1/products?per_page=100&orderby=popularity" -o prods.json
node scripts/gen-details.mjs  # описания, характеристики, галереи
node scripts/gen-legal.mjs    # политика конфиденциальности и оферта
```

## Мобильная версия

- Один брейкпоинт-ориентир: `md` (768px), плюс `lg` (1024px) для навигации.
- Высоты экранов на `100svh` — адресная строка мобильных браузеров не ломает вёрстку.
- Фиксированная нижняя панель «Позвонить / WhatsApp» появляется после первого экрана.
- Все кликабельные элементы — не меньше 40–44px по высоте.
- Учитывается `prefers-reduced-motion` и `env(safe-area-inset-bottom)`.

## Замечания

- Формы без бэкенда: и заявка в блоке контактов, и оформление заказа открывают
  WhatsApp с готовым сообщением. Если появится серверная часть — менять нужно
  только `onSubmit` в `Contacts` и `submit` в `CartDrawer`.
- Оплаты на сайте нет: корзина собирает заказ, а расчёт идёт как сейчас —
  наличными, картой, переводом или наложенным платежом.
- Ссылки категорий и кнопки «Смотреть» ведут на секцию с товарами. При переезде
  на полноценный каталог их нужно заменить на реальные URL.

## Автодеплой (опционально)

Сейчас сайт выкладывается в ветку `gh-pages` вручную. Чтобы включить сборку на
GitHub Actions, нужен токен со scope `workflow`:

```bash
gh auth refresh -s workflow
mkdir -p .github/workflows
cp docs/github-pages-workflow.yml .github/workflows/deploy.yml
git add .github && git commit -m "Добавить автодеплой на GitHub Pages" && git push
```

После этого в **Settings → Pages** источник нужно переключить на *GitHub Actions*.
