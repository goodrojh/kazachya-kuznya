# Казачья Кузня — лендинг

Одностраничный продающий сайт для производителя шашек, сабель, палашей, шпаг,
кинжалов и ножей «Казачья Кузня».

Контент (тексты, цены, артикулы, FAQ, реквизиты, отзывы) взят с действующего
сайта **kazachya-kuznya.ru** и с профиля компании на Авито.

## Стек

- React 19 + TypeScript
- Vite
- Tailwind CSS 3 (без внешних UI- и icon-библиотек)

## Структура

```
site/
  src/App.tsx      — вся разметка, хуки и компоненты
  src/data.ts      — контент: каталог, товары, отзывы, FAQ, контакты
  src/index.css    — базовые стили и утилиты
  public/img/      — изображения в WebP (~1,4 МБ на 34 файла)
  scripts/         — загрузка и оптимизация исходных изображений
```

## Разделы страницы

1. **Прелоадер** — счётчик 0→100 с полосой прогресса.
2. **Первый экран** — три факта-полосы и главная карточка. Все четыре карточки
   показывают разные «окна» одного фонового снимка цеха (техника masked cards).
3. **Каталог** — 8 категорий с количеством позиций.
4. **Изделия** — 24 товара с фильтром по категориям, ценами, скидками и
   артикулами. Кнопка заказа открывает WhatsApp с подставленным названием и
   артикулом.
5. **Производство** — конструктивные особенности, ГОСТ Р 51215-98, 5 преимуществ.
6. **Отзывы** — 9 реальных отзывов покупателей.
7. **Доставка и вопросы** — аккордеон из 8 вопросов, службы доставки, сроки.
8. **Контакты** — телефон, почта, мессенджеры и форма заявки (уходит в WhatsApp).
9. **Подвал** — реквизиты ИП и юридическая оговорка.

## Разработка

```bash
cd site
npm install
npm run dev
```

## Сборка

```bash
cd site
npm run build
```

Продакшн-сборка публикуется на GitHub Pages через
`.github/workflows/deploy.yml` при пуше в `main`. Базовый путь задаётся
переменной `BASE_PATH`.

## Обновление изображений

```bash
cd site
node scripts/fetch-src.mjs   # скачивает исходники в site/raw
node scripts/optimize.mjs    # конвертирует в WebP в public/img
```

## Мобильная версия

- Один брейкпоинт-ориентир: `md` (768px), плюс `lg` (1024px) для навигации.
- Высоты экранов на `100svh` — адресная строка мобильных браузеров не ломает вёрстку.
- Фиксированная нижняя панель «Позвонить / WhatsApp» появляется после первого экрана.
- Все кликабельные элементы — не меньше 40–44px по высоте.
- Учитывается `prefers-reduced-motion` и `env(safe-area-inset-bottom)`.

## Замечания

- Форма заявки без бэкенда: отправка открывает WhatsApp с готовым сообщением.
  Если появится серверная часть — менять нужно только обработчик `onSubmit`
  в компоненте `Contacts`.
- Ссылки категорий и кнопки «Смотреть» ведут на секцию с товарами. При переезде
  на полноценный каталог их нужно заменить на реальные URL.

## Автодеплой (опционально)

Сейчас сайт выкладывается в ветку `gh-pages` вручную. Чтобы включить сборку на
GitHub Actions, нужен токен со scope `workflow`:

```bash
gh auth refresh -s workflow
mkdir -p .github/workflows
cp docs/github-pages-workflow.yml .github/workflows/deploy.yml
git add .github && git commit -m "Добавить автодеплой на GitHub Pages" && git push
```

После этого в **Settings → Pages** источник нужно переключить на *GitHub Actions*.
